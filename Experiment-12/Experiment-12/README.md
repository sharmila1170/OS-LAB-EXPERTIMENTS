# Experiment 12 – Page Replacement Algorithms

This folder contains the Windows-compatible C implementation prepared from the OS lab manual.

## Files
- fifo.c
- lru.c
- optimal.c
- output.md

## Compile and Run
Use GCC in the VS Code terminal:

```powershell
gcc filename.c -o filename
.\filename
```

For experiments with multiple programs, compile each `.c` file separately.

## Note
The manual's Linux/POSIX programs for Experiments 5, 6 and 9 use UNIX/POSIX APIs. Those programs are adapted to Windows APIs so they can run with your Windows GCC setup while demonstrating the same experiment concept/output.
